# Data model

Postgres/Supabase schema for a personal book library. All tables use `authenticated`-only RLS policies (no public access).

## Tables

### `livres_livres` (books) — central table
| Column | Type | Notes |
|---|---|---|
| `id` | integer PK | |
| `titre` | varchar(200) | title, required |
| `titreVo` | varchar(200) | original-language title |
| `numEdition` | integer | edition number |
| `anneePremiereEdition` | integer | year of first edition |
| `numEditeur_id` | FK → `livres_editeur` | publisher |
| `genre_id` | FK → `livres_genre` | |
| `typeLivre_id` | FK → `livres_typelivre` | |
| `auteur_id` | FK → `livres_auteur` (nullable) | author |
| `illustrateur_id` | FK → `livres_illustrateur` (nullable) | |
| `collection` | boolean | part of a collection |
| `serie` / `num_serie` | varchar / integer | series name and position |
| `dateSaisie` | timestamp | date record was entered |
| `dateDebutLecture` / `dateFinLecture` | timestamp | reading start/end dates |
| `note` | real | rating |
| `image`, `description`, `commentaires`, `dedicace`, `emprunteur` | text fields | cover image, description, comments, dedication, current borrower |

### `livres_auteur` (authors)
`id`, `nom`, `prenom`, `anneeNaissance`, `nationalite_id` → FK to `livres_pays`.

### `livres_illustrateur` (illustrators)
Same shape as `livres_auteur`: `id`, `nom`, `prenom`, `nationalite_id` → FK to `livres_pays`.

### `livres_editeur` (publishers)
`id`, `nom`, `adresse`.

### `livres_pays` (countries)
`id`, `nom`. Referenced by both authors and illustrators as nationality.

### `livres_genre` (genres)
`id`, `genre` (label).

### `livres_typelivre` (book types)
`id`, `type` (label, e.g. novel/comic/etc.).

## Relationships

```
livres_pays ──< livres_auteur ──┐
livres_pays ──< livres_illustrateur ──┤
livres_editeur ──< livres_livres ─────┼── livres_livres
livres_genre ──< livres_livres ───────┤
livres_typelivre ──< livres_livres ───┘
```

`livres_livres` is the fact table referencing author, illustrator, publisher, genre, and book type; authors/illustrators each reference a country.

## Notes
- IDs are `GENERATED BY DEFAULT AS IDENTITY`.
- Indexes exist on all FK columns in `livres_livres`, plus nationality FKs on authors/illustrators.
- `dateSaisie`, `dateDebutLecture`, `dateFinLecture` are declared `NOT NULL`/`timestamp` in `schema.sql`, but in the live Supabase DB the `NOT NULL` constraint was dropped on all three to allow legitimately-empty values (e.g. unread books) from the source data dump.
